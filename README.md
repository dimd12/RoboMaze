# RoboMaze

RoboMaze is a maze game developed in Java. The player programs a robot to navigate a maze by creating a sequence of movement and turning commands. The application includes procedural maze generation, animated command execution, and shortest-path visualization.

## Requirements

- Java Development Kit (JDK) 21
- Apache Maven

## File Locations

The written reflection, final product backlog, and executable jar are all under the /deliverables folder.

## Running RoboMaze

### Run the packaged JAR

From the deliverables/ folder, run the RoboMaze.jar file to run the project.

### Build and run from source

Alternatively, download the source code and call the Launch.java's main() method to run the game.

## How to Play

1. Launch the application.
2. Open the game from the main menu.
3. Generate a maze using the available maze-generation controls.
4. Add movement and turning commands to the robot's program.
5. Execute the commands to watch the robot navigate the maze.
6. Use the shortest-path feature to visualize a shortest route to the target.
7. Reset the game to try another sequence of commands.

The application also includes a How to Play screen with in-game instructions.

## Features

- Procedural maze generation
- Configurable maze dimensions
- Robot command programming
- Animated execution of commands
- Shortest-path calculation using breadth-first search (BFS)
- Maze rendering and robot movement visualization
- Main menu and in-game instructions

## Technologies

- Java 21
- JavaFX and FXML
- Apache Maven
- Depth-first search (DFS) for maze generation
- Breadth-first search (BFS) for shortest-path finding
